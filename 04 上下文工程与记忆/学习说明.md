# 04 上下文工程与记忆

先阅读 `课件/` 中的 PDF，再按 04A～04C 的顺序打开 `Notebook/`。

| 实践 | 内容 | 运行条件 |
| --- | --- | --- |
| 04A | 消息选择、预算和工具消息完整性 | Python 标准库 |
| 04B | 持久记忆、三组回答对照与审计 | pandas；默认读取 `数据/实验记录/deepseek-context.json` |
| 04C | KV Cache、Prompt 排列与服务端缓存记录 | 默认读取 `数据/实验记录/` 中的模型观测文件，不下载权重 |

`代码/` 放课程源码和自检，`数据/` 放自编学习会话与离线实验记录。请保留完整节目录，并从资料根目录启动 JupyterLab。04B 的真实模型请求默认关闭；只有自行配置密钥、确认费用后，将 `RUN_LIVE` 改为 `True` 才会发起请求。

04C 的服务端缓存记录保留了采集时课程文档的哈希，并移除了含教师工作区文字的请求消息；学生版核对记录结构与用量，不重新计算该原文哈希。Notebook 的保存输出和实验记录均是历史观测，不代表当前模型或服务状态。
